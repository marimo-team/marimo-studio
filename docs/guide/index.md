# Guide

Keep analytical logic in a saved Marimo notebook, then create one
view project for each audience or task. The guides cover the
path from starter selection to a published artifact.

| Task                                             | Guide                                               |
| ------------------------------------------------ | --------------------------------------------------- |
| Reach one working custom view                    | [Create your first view](getting-started.md)        |
| Add, switch, link, inspect, and remove views     | [Create and manage views](views.md)                 |
| Bring any frontend source and toolchain          | [Choose an authoring option](authoring-options.md)  |
| Mount cells, outputs, and values                 | [Use notebook results](notebook-results.md)         |
| Work with frontend source and previews           | [Author with the live workspace](live-authoring.md) |
| Author and validate views with a coding agent    | [Agent-native authoring](coding-agents.md)          |
| Serve through Marimo or export for a static host | [Run, export, and share](run-and-share.md)          |

::: tip Start with an existing notebook
[Create your first view](getting-started.md) creates a valid view project,
publishes its development artifact, and opens the notebook and selected view
together.
:::
