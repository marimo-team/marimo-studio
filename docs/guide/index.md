# Guide

New to Studio? Read [What is Studio?](../what-is-studio.md), then build a first
view in [Getting started](getting-started.md) or ask for one in
[Author with a coding agent](coding-agents.md).

| Theme a page and the notebook output it places                             | [Style a page](styling.md)                              |
